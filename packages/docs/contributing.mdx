# Contributing

See project guidelines for contributing.

## Process

1. Fork and clone
2. `npm install`
3. Develop components with `npm run storybook`
4. Write tests and a11y checks
5. Run `npm test` and `npm run build -w yash-design-system`
6. Open pull request

## Standards

- TypeScript strict
- Design tokens only; no CSS frameworks in components
- Accessibility-first patterns and testing
- Keep bundles small and tree-shakeable

More details in `CONTRIBUTING.md`.
